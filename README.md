# Restaurant-website
A basic user friendly food website design  using html , css and javascript .
This is a responsive and user-friendly food website designed to showcase restaurant menus, promote featured dishes, and offer a seamless experience for users to explore culinary options. Built using HTML, CSS, and JavaScript, this project is ideal for restaurants, cafes, or food delivery services looking to establish an online presence.

Key Features:

Interactive and mobile-responsive design

Home, About, Menu, Contact, and Booking sections

Smooth navigation and attractive layout

Integrated food item cards with images, names, and prices

Clean and modular code for easy customization
